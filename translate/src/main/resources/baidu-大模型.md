 
# 百度翻译开放平台 - 大模型文本翻译 API 接入文档

全新大模型文本翻译 API，依托强大的大模型理解能力，提供更精准自然的多语种翻译。支持翻译指令，实现风格、语气和场景定制；支持术语库管理，确保专业词汇统一一致。适用于电商、教育、内容生产等多种业务场景。

---

## 1. 产品功能

* **文本翻译**（基础能力）
* **切换模型**：可选“大模型翻译”（`llm`）或“机器翻译”（`nmt`）
* **自定义术语库**：可在 [我的术语库](https://fanyi-api.baidu.com/doc/21) 页面上传，提升翻译质量
* **翻译指令**：如“采用意译”、“使用学术风格”（仅大模型翻译支持）
* **标签保持**：原文中包含 XML 标签，可在译文中还原保持
* **指定内容不翻译**：可指定 XML 标签包裹的内容不翻译

---

## 2. 接入步骤

1. 使用百度账号登录 [百度翻译开放平台](https://fanyi-api.baidu.com/)。
2. 完成注册，并在 [开发者信息](https://fanyi-api.baidu.com/doc/21) 页面获取 **APPID** 与 **密钥**，或创建并使用 **API Key** 方式鉴权。
3. 进行开发者认证。
4. 开通 [大模型文本翻译 API 服务](https://fanyi-api.baidu.com/doc/21)。
5. 参考本文档编写代码进行对接。

## 3. 接口指南

### 3.1 请求地址

* **URL**：`https://fanyi-api.baidu.com/ait/api/aiTextTranslate`
* **HTTP 请求方式**：`GET` 或 `POST`
  * 使用 `POST` 时，Header 中 `Content-Type` 可指定为 `application/x-www-form-urlencoded` 或 `application/json`
* **字符编码**：统一采用 `UTF-8`

---

### 3.2 鉴权方式

推荐使用 **API Key 鉴权**；也兼容传统 **MD5 Sign 鉴权**。

#### 方式一：API Key 鉴权（推荐）

在 HTTP 请求 Header 中添加以下字段：

```http
Authorization: Bearer YOUR_API_KEY
```

> API Key 可在【管理控制台】-【[API Key管理](https://fanyi-api.baidu.com/doc/21?utm_source=gemini)】页面创建。

#### 方式二：Sign 鉴权

1. **拼接字符串 1**：按 `appid + q + salt + 密钥` 的顺序拼接（`q` 不需要做 URL encode）。
2. **计算签名**：对字符串 1 进行 **MD5** 加密，得到 32 位小写字符串 `sign`。
3. **发送请求**：在发送 HTTPS 请求前，对待翻译文本 `q` 做 URL encode。

---

### 3.3 输入参数

> **注**：单次请求文本长度建议控制在 2,000 字符以内（上限 6,000 字符）。

| **参数名**   | **类型** | **是否必填** | **描述**             | **备注**                                                          |
| -------------------- | ---------------- | -------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| **appid**         | string         | 是                 | APPID                      | 可在[开发者信息](https://fanyi-api.baidu.com/doc/21?utm_source=gemini)查看 |
| **q**             | string         | 是                 | 请求翻译文本               | UTF-8 编码，上限 6,000 字符                                             |
| **from**          | string         | 是                 | 源语言代码                 | 可设置为`auto`（自动检测）                                          |
| **to**            | string         | 是                 | 目标语言代码               | **不可**设置为`auto`                                               |
| **needIntervene** | integer        | 否                 | 是否使用自定义术语干预 API | `1`- 是，`0`- 否                                                |
| **model\_type**   | string         | 否                 | 选择翻译模型               | `'llm'`- 大模型翻译（默认）；`'nmt'`- 机器翻译                  |
| **reference**     | string         | 否                 | 自定义翻译指令             | 格式要求如：“使用学术风格来翻译”（仅`llm`支持）                   |
| **tag\_handling** | integer        | 否                 | 标签保持功能               | `1`- 开，`0`- 关（默认）；仅支持`model_type='nmt'`          |
| **ignore\_tags**  | array          | 否                 | 自定义标签间内容不翻译     | 最多 20 个标签，如`['name', 'address']`；需开启`tag_handling=1` |
| **salt**          | string         | 否                 | 随机数                     | 使用 Sign 鉴权时必填                                                    |
| **sign**          | string         | 否/是              | 签名                       | 使用 Sign 鉴权时必填（`MD5(appid+q+salt+密钥)`）                    |

---

### 3.4 输出参数及示例

接口返回标准 JSON 格式数据。

#### 请求成功示例：

**JSON**

```
{
    "from": "en",
    "to": "zh",
    "trans_result": [
        {
            "src": "apple",
            "dst": "苹果"
        }
    ]
}
```

#### 请求异常示例：

**JSON**

```
{
    "error_code": "54001",
    "error_msg": "Invalid Sign"
}
```

## 4. 调用示例 (cURL)

**Bash**

```
curl -X POST "[https://fanyi-api.baidu.com/ait/api/aiTextTranslate](https://fanyi-api.baidu.com/ait/api/aiTextTranslate)" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "appid": "YOUR_APPID",
    "from": "zh",
    "to": "en",
    "q": "你好"
  }'
```

## 6. 错误码说明

| **错误码** | **含义**        | **解决方案**                                                    |
| ------------------ | ----------------------- | ----------------------------------------------------------------------- |
| **52000**       | 成功                  | -                                                                     |
| **52001**       | 请求超时              | 检查`q`参数是否包含正常文本，或`from`/`to`语种是否支持    |
| **52002**       | 系统错误              | 请稍后重试                                                            |
| **52003**       | 未授权用户            | 请检查`appid`是否正确，或服务是否已开通                           |
| **54000**       | 必填参数为空          | 检查是否漏传必填参数                                                  |
| **54001**       | 签名错误 / Token 错误 | 检查签名生成算法（拼接前`q`无需 URL encode），或检查 Token 正确性 |
| **54003**       | 访问频率受限          | 降低调用频率，或切换为高级版/尊享版                                   |
| **54004**       | 账户余额不足          | 前往控制台充值                                                        |
| **54005**       | 长 query 请求频繁     | 降低单次大于 1 万字节的请求频率，3 秒后再试                           |
| **58000**       | 客户端 IP 非法        | 检查控制台预留的服务器 IP 是否匹配，若为动态 IP 可留空                |
| **58004**       | 模型参数错误          | 检查`model_type`参数是否为`llm`或`nmt`                    |
| **59002**       | 翻译指令过长          | `reference`参数不得超过 500 字符上限                              |
| **59003**       | 请求文本过长          | `q`参数不得超过 6000 字符上限                                     |
| **59004**       | QPS 超限              | 当前调用触及 QPS 上限，请稍后重试或提额                               |
| **20003**       | 请求内容存在安全风险  | 检查输入文本是否包含敏感词汇                                          |

