 
# 百度翻译开放平台 - 通用文本翻译 API 接入文档

百度通用翻译 API 是基于先进自然语言处理技术打造的在线文本翻译服务，支持 200+ 种语言互译及 100+ 语种自动检测。支持单次提交待翻译文本，指定源语言与目标语言即可实时获取结果。

---

## 1. 产品简介

* **功能特点**：支持多语种互译、源语言自动检测，适用于移动端、PC 网站及智能硬件等多场景。
* **扩展支持**：支持自定义术语库干预翻译结果。

---

## 2. 接入步骤

1. 使用百度账号登录 [百度翻译开放平台](https://fanyi-api.baidu.com)。
2. 完成注册，并在 [开发者信息](https://fanyi-api.baidu.com/developer) 页面获取 **APPID** 与 **密钥**。
3. 进行开发者认证（标准版可跳过）。
4. 开通通用翻译 API 服务。
5. 参考示例代码和 Demo 进行开发。

---

## 3. 接入指南

### 3.1 请求地址

* **URL**：`https://fanyi-api.baidu.com/api/trans/vip/translate`
* **请求方式**：`GET` 或 `POST`
  * 若使用 `POST` 方式，Header 的 `Content-Type` 请指定为：`application/x-www-form-urlencoded`
* **字符编码**：`UTF-8`
* **长度限制**：建议单次请求控制在 2,000 字符以内（认证后上限 6,000 字符/字节）。

---

### 3.2 输入参数

| 字段名 | 类型 | 是否必填 | 描述 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **q** | string | 是 | 请求翻译文本 | UTF-8 编码，认证后上限 6000 字符 |
| **from** | string | 是 | 源语言代码 | 可设置为 `auto`（自动检测） |
| **to** | string | 是 | 目标语言代码 | **不可**设置为 `auto` |
| **appid** | string | 是 | 开发者 APPID | 可在 [开发者信息](https://fanyi-api.baidu.com/developer) 查看 |
| **salt** | string | 是 | 随机数 | 字母或数字字符串 |
| **sign** | string | 是 | 签名 | 算法为 `MD5(appid + q + salt + 密钥)` |
| **needIntervene** | integer | 否 | 自定义术语干预开关 | `1`-开启，`0`-关闭（需开通我的术语库） |

---

### 3.3 签名计算规则（sign）

1. **拼接字符串 1**：按 `appid + q + salt + 密钥` 顺序拼接（**注意**：拼接时 `q` **不需要**做 URL encode）。
2. **计算 MD5**：对字符串 1 进行 MD5 加密，生成 **32 位小写** 字符串。
3. **发送请求**：生成签名后，在发送 HTTP 请求或拼接到 URL 前，必须对待翻译文本 `q` 进行 **URL encode**。

---

### 3.4 输出参数及示例

接口返回 JSON 格式数据。

#### 字段说明：
* `from`：源语言
* `to`：目标语言
* `trans_result`：翻译结果数组，包含原文 `src` 与译文 `dst`
* `error_code`：错误码（仅异常时返回）

#### 请求成功示例：
```json
{
    "from": "en",
    "to": "zh",
    "trans_result": [
        {
            "src": "apple",
            "dst": "苹果"
        }
    ]
}
```

#### 请求失败示例：

**JSON**

```
{
    "error_code": "54001",
    "error_msg": "Invalid Sign"
}
```

## 5. 错误码说明

| **错误码** | **含义**       | **解决方案**                                                 |
| ------------------ | ---------------------- | -------------------------------------------------------------------- |
| **52000**       | 成功                 | -                                                                  |
| **52001**       | 请求超时             | 检查`q`参数是否包含正常文本，或`from`/`to`语种是否支持 |
| **52002**       | 系统错误             | 请稍后重试                                                         |
| **52003**       | 未授权用户           | 检查`appid`是否正确，或服务是否已开通                          |
| **54000**       | 必填参数为空         | 检查是否漏传或误传参数                                             |
| **54001**       | 签名错误             | 检查签名加密算法，注意拼接时`q`无需 URL encode                 |
| **54003**       | 访问频率受限         | 降低请求频率，或完成认证切换为高级版/尊享版                        |
| **54004**       | 账户余额不足         | 前往控制台充值                                                     |
| **54005**       | 长 query 请求频繁    | 降低长度大于 1 万字节请求的频率，3 秒后再试                        |
| **58000**       | 客户端 IP 非法       | 检查开发者信息中绑定的服务器 IP；若为动态 IP 请留空                |
| **58001**       | 译文语言方向不支持   | 检查语种代码是否在支持列表中，部分极小语种仅支持尊享版             |
| **58002**       | 服务当前已关闭       | 前往控制台开启服务                                                 |
| **58003**       | 此 IP 已被封禁       | 单 IP 多 APPID 触发风控封禁，次日解封；请勿在第三方软件泄露 Key    |
| **20003**       | 请求内容存在安全风险 | 检查输入文本是否涉及敏感词汇                                       |

## 6. 常见问题 (FAQ)

1. **多段文本/单词如何同时翻译？**
   在 `q` 字段中使用换行符 `\n` 分隔多段内容，请求前需整体进行 URL encode。
2. **为什么频繁报 54001 签名错误？**
   
   * 生成签名的拼接顺序为 `appid + q + salt + 密钥`，​**此时 `q` 不能做 URL encode**​。
   * 拼接完成计算出 MD5 值（小写 32 位）后，在实际发送请求时，才对 `q` 进行 URL encode。
3. ​**频率限制（QPS）说明**​：
   
   * 标准版：QPS = 1
   * 个人认证高级版：QPS = 10
   * 企业认证尊享版：QPS = 100
