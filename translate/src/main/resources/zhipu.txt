GLM 模型 OpenAI 兼容 API 接入指南
📋 概述
智谱 GLM 系列模型提供 OpenAI 兼容接口，你可以直接使用 OpenAI SDK 或任何支持 OpenAI 格式的工具（如 LangChain、LlamaIndex、Dify、OneAPI 等）接入，只需修改 base_url 和 api_key 即可。
🔑 1. 获取 API Key
访问开放平台并注册账号
进入控制台 → API 密钥 页面
创建并复制你的 API Key
⚠️ 请妥善保管 API Key，不要暴露在前端代码或公开仓库中。
⚙️ 2. 基础配置
配置项	值	
Base URL	https://open.bigmodel.cn/api/paas/v4/	
鉴权方式	Authorization: Bearer <your-api-key>	
协议格式	OpenAI 兼容	
支持流式	✅ stream=true	
🐍 3. Python 接入示例
3.1 使用 OpenAI SDK（推荐）
from openai import OpenAI
client = OpenAI(
    api_key="your-api-key",
    base_url="https://open.bigmodel.cn/api/paas/v4/"
)
response = client.chat.completions.create(
    model="glm-4-flash",          # 按需替换模型名
    messages=[
        {"role": "system", "content": "你是一个乐于助人的AI助手。"},
        {"role": "user", "content": "介绍一下你自己"}
    ],
    temperature=0.7,
    max_tokens=1024,
    stream=False
)
print(response.choices[0].message.content)
3.2 流式输出
stream = client.chat.completions.create(
    model="glm-4-flash",
    messages=[{"role": "user", "content": "写一首关于春天的诗"}],
    stream=True
)
for chunk in stream:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
3.3 使用原生 zhipuai SDK
from zhipuai import ZhipuAI
client = ZhipuAI(api_key="your-api-key")
response = client.chat.completions.create(
    model="glm-4-plus",
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
🖥️ 4. cURL 示例
curl -X POST "https://open.bigmodel.cn/api/paas/v4/chat/completions" \
  -H "Authorization: Bearer your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-4-flash",
    "messages": [
      {"role": "user", "content": "你好"}
    ],
    "stream": false
  }'

🎛️ 6. 核心参数说明
参数	类型	说明	
model	string	模型名称，必填	
messages	array	对话消息列表，支持 system / user / assistant	
temperature	float	采样温度（0~1），越高越随机	
top_p	float	核采样参数	
max_tokens	int	最大输出 token 数	
stream	bool	是否流式返回	
tools	array	Function Calling 工具定义	
stop	array	停止词列表
